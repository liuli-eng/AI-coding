# 第一阶段：照这个顺序操作

以下命令都在 `project` 目录执行。

## 1. 执行一个 SQL

数据库：`aicoding-assistant`。

文件：`backend/docs/script/sql/update/2026-10-28-phase1-foundation-rag.sql`。

本机直接复制执行：

```sh
docker exec -i aicoding-assistant-mysql sh -c 'MYSQL_PWD="$MYSQL_ROOT_PASSWORD" exec mysql -uroot --database=aicoding-assistant --default-character-set=utf8mb4' < backend/docs/script/sql/update/2026-10-28-phase1-foundation-rag.sql
```

## 2. 启动或重启服务

| 服务 | 你需要做什么 |
| --- | --- |
| MySQL、Redis | 目前都在运行，保持运行即可 |
| Java 后端 | 使用 Java 17，按原来的启动配置重新启动 `RuoYiAIApplication`，端口 `8080` |
| 用户网页 | 已开着就刷新；未启动则运行 `pnpm --dir web dev`，端口 `5173` |
| 管理后台 | 已开着就刷新；未启动则运行 `pnpm --dir admin dev:antd`，端口 `5666` |

后端启动文件：`backend/aicoding-admin/src/main/java/org/ruoyi/RuoYiAIApplication.java`。

## 3. 打开页面检查

执行 SQL、重启后端后，管理员退出再登录。按下面顺序检查：

| 检查什么 | 你怎么操作 | 正常应该怎样 |
| --- | --- | --- |
| 1. 后台菜单 | 打开管理后台，依次点“问答记录”“异常问题排查”“Prompt 管理”“课程管理”“业务数据总览” | 都能打开，没有报错；没有数据时显示空列表即可 |
| 2. 提示词模板 | 在“Prompt 管理”新增“验收模板”，模式选“编程助手”，填写内容并启用，保存后刷新；再到用户端新建对话 | 模板仍在，新对话的“提示词模板”能选到它 |
| 3. 课程 | 在“课程管理”新增“验收课程”，添加一章并设为“已发布”；用户端点“我的课程”，加入该课程，标记一章完成后刷新 | 能看到课程，完成进度仍保留 |
| 4. 知识库搜索 | 打开用户端知识库，搜索一个已有的知识库名称 | 能找到对应知识库；搜不存在的名称时显示没有结果 |
| 5. 知识库问答 | 选一个已上传并处理好资料的知识库，点“开始对话”，问一个资料里有答案的问题 | 输入框上方显示所选知识库名称，回答与资料一致 |
| 6. 问答记录 | 回管理后台的“问答记录”，点“刷新记录”，找到刚才的问题，再点“查看详情” | 有刚才的问题和回答；确实用到资料时，能看到对应知识库及引用文档、片段 |
| 7. 会话不会串库 | 刷新刚才的对话；再新建对话选择另一个库，最后切回原对话 | 刷新后库名不变；切回原对话时仍是原来的库；新对话默认不选库 |
| 8. 普通用户权限 | 用普通账号登录用户端和管理端 | 能使用有权访问的知识库；看不到新增的后台管理菜单及其他人的私有知识库 |

知识库列表为空时，先准备一个当前账号能访问、已有处理完成资料的知识库，再检查第 5、6、7 项。

入口：[管理后台](http://localhost:5666) · [用户知识库](http://localhost:5173/knowledge)。

检查完告诉我结果，确认后再做第二阶段。
