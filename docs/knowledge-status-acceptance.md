# 知识库启用／停用：这样检查

本机 SQL 已执行，不用再执行 SQL。用 Java 17 重启后端 `RuoYiAIApplication`（6039），然后刷新后台和客户端。前端服务继续使用原来的 5666、5173。

1. 打开后台“知识库 → 知识库列表”，找到一个客户端可见、已有文档的知识库；客户端先用它开始一次对话。
2. 后台将这个知识库的“状态”关为“停用”。
3. 切回客户端“知识库”，确认它从列表消失。打开刚才的对话，确认提示“知识库已停用”；继续提问应被拒绝。
4. 后台重新启用。切回客户端或刷新，确认知识库重新出现，原对话可以继续使用。

停用会保留全部文档和聊天记录。没有编辑权限的后台账号只能查看状态。

其他环境先执行增量脚本 `backend/docs/script/sql/update/2026-10-29-knowledge-status.sql`，再启动新版后端。不要执行全量初始化 SQL。
